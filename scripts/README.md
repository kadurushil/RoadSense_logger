# RoadSense Offline Telemetry & Sensor Diagnostics Suite

> **Location:** `scripts/`  
> **Target Environment:** Python 3.8+ (Standard Library only — zero external pip dependencies required)  
> **Purpose:** Authoritative diagnostic, auditing, and verification toolset for RoadSense multi-sensor drive recording sessions.

---

## 1. Master Session Health Check (`session_health_check.py`)

### What It Does:
Runs a single, end-to-end audit on a drive session and outputs an executive pass/warn/fail scorecard across all 7 subsystems:
1. **Session Lifecycle:** Start time, stop time, active streams, duration.
2. **Camera:** MP4 container size, total frames, measured FPS, drop percentage.
3. **Radar:** Valid TI frames (magic word verification), detected targets, packet drop rate.
4. **GNSS:** Total fixes, fix rate (Hz), horizontal accuracy (CEP), peak velocity.
5. **CANedge:** Staged chunks, MDF4 headers (`MDF ` / `UnFinMF `), byte volumes.
6. **Timeline:** Synchronized event count and per-stream distribution.
7. **Flight Recorder:** Errors, exceptions, and lifecycle state transitions.

### Usage:
```powershell
# Audit the most recent session automatically
python scripts/session_health_check.py --latest

# Audit a specific session by folder name
python scripts/session_health_check.py session_20260911_141256

# Audit a session by full absolute path
python scripts/session_health_check.py "C:\path\to\RoadSense\logs\session_20260911_141931"
```

## 2. Radar Binary Stream Validator (`validate_radar_stream.py`)

### What It Does:
Directly parses the raw binary byte stream generated by the TI AWR1843BOOST radar data port over USB-UART (3,125,000 baud):
* Locates the 8-byte sync word (`0x0102030405060708` / `b'\x02\x01\x04\x03\x06\x05\x08\x07'`).
* Unpacks packet headers to extract frame sequence numbers, CPU cycle counts, and subframe IDs.
* Unpacks TLV structures:
  * **TLV 1:** `DETECTED_POINTS` (Point cloud Doppler velocity, range, and azimuth coordinates).
  * **TLV 2:** `RANGE_PROFILE` (1D FFT energy peaks).
  * **TLV 3:** `NOISE_PROFILE` (CFAR noise floor).
  * **TLV 10/11:** Target tracking lists and cluster indices.
* Analyzes sequence continuity, detects UART ring-buffer overflows, and calculates the exact frame delivery rate (e.g. 99.95%).

### Usage:
```powershell
# Validate radar on the latest session
python scripts/validate_radar_stream.py --latest

# Validate radar on a specific session
python scripts/validate_radar_stream.py session_20260911_141931

# Validate an explicit binary file
python scripts/validate_radar_stream.py "logs/session_20260911_141256/radar/radar_raw_stream.bin"
```

## 3. Camera Video & Frame Timing Validator (`validate_camera_video.py`)

### What It Does:
Validates the optical video stream and hardware shutter synchronization:
* Reads `camera_frames.csv` to calculate inter-frame shutter time deltas ($\Delta t = t_i - t_{i-1}$).
* Computes mean interval, minimum/maximum frame interval, and standard deviation (jitter).
* Detects frame drops using two thresholds:
  * $\Delta t > 50.0\text{ ms}$: Single missed frame at 30 FPS.
  * $\Delta t > 66.7\text{ ms}$: Severe drop (2+ frames missed).
* Correlates frame count with the MP4 container size to verify video encoder bitrate consistency.

### Usage:
```powershell
# Validate camera video on latest session
python scripts/validate_camera_video.py --latest

# Validate camera on a specific session
python scripts/validate_camera_video.py session_20260911_141256
```

## 4. GNSS Location & Fix Validator (`validate_gnss_fixes.py`)

### What It Does:
Validates GNSS positioning, kinematic telemetry, and satellite constellation health:
* Computes Circular Error Probable (CEP 50% median and CEP 95% worst-case horizontal accuracy in meters).
* Calculates cumulative distance traveled using the great-circle Haversine formula:
  $$d = 2R \arcsin \left(\sqrt{\sin^2\left(\frac{\Delta \phi}{2}\right) + \cos \phi_1 \cos \phi_2 \sin^2\left(\frac{\Delta \lambda}{2}\right)}\right)$$
* Extracts velocity percentiles, altitude range, and bounding box coordinates.
* Audits constellation tracking (satellites used vs satellites in view).

### Usage:
```powershell
# Validate GNSS on latest session
python scripts/validate_gnss_fixes.py --latest

# Validate GNSS on a specific session
python scripts/validate_gnss_fixes.py session_20260911_141931
```

## 5. CANedge Staging & MDF4 Validator (`validate_canedge_staging.py`)

### What It Does:
Audits CANedge2 MDF4 chunks stored in either a session `can/` directory or the phone staging pool (`canedge_pool/`):
* Reads the first 8 bytes of each file to confirm standard ASAM MDF4 signatures:
  * `MDF     `: Finalized MDF4 chunk.
  * `UnFinMF `: Unfinished MDF4 chunk (standard for cyclic logging on CANedge).
* Verifies sequential folder and index ordering (e.g. `00000047_00000067.MF4` $\rightarrow$ `00000047_00000068.MF4`).
* Flags missing sequence gaps or truncated file downloads.

### Usage:
```powershell
# Validate CAN chunks on latest session
python scripts/validate_canedge_staging.py --latest

# Validate CAN chunks for a specific session
python scripts/validate_canedge_staging.py session_20260911_141256

# Audit the staging cache pool directly
python scripts/validate_canedge_staging.py --pool
```

## 6. Cross-Sensor Synchronization Auditor (`audit_cross_sensor_sync.py`)

### What It Does:
Audits the master monotonic index file (`session_timeline.csv`) to measure cross-sensor synchronization quality:
* Validates hardware nanosecond monotonic alignment (`SystemClock.elapsedRealtimeNanos()`).
* Calculates the latency between each Radar point cloud frame and the closest Camera video shutter frame using binary search:
  $$\Delta t_{\text{sync}} = \min_j |t_{\text{radar}, i} - t_{\text{camera}, j}|$$
* Evaluates alignment quality against the theoretical Nyquist optimum for 30 FPS video ($\Delta t_{\text{opt}} < 16.67\text{ ms}$).

### Usage:
```powershell
# Audit synchronization on latest session
python scripts/audit_cross_sensor_sync.py --latest

# Audit synchronization on a specific session
python scripts/audit_cross_sensor_sync.py session_20260911_141931
```

## 7. Flight Recorder Search Tool (`search_flight_recorder.py`)

### What It Does:
High-speed log analysis engine that scans across all app runs (`logs/app_logs/app_run_*/app_system.log`) and session logs (`logs/session_*/session_debug.log`):
* Searches for specific keywords, device events, or sensor tags.
* Filters for errors, coroutine crashes, or warnings.
* Traces background CAN download tasks, smart auto-pruning actions, and rescued boundary chunks.

### Usage:
```powershell
# Search for auto-pruned or rescued CAN chunks across all runs
python scripts/search_flight_recorder.py --query "Rescued"

# Search for all errors and exceptions across all logs
python scripts/search_flight_recorder.py --errors

# Search for events related to a specific session
python scripts/search_flight_recorder.py --session session_20260911_141256

# Search with a custom result limit
python scripts/search_flight_recorder.py --query "CameraEngine" --max 50
```
